# Переводчик экрана (Android)

Поверх любого приложения висит кнопка **RU**. Нажали — китайский текст на экране закрывается жёлтыми плашками с русским переводом (с сокращениями). Нажатие на плашку — полный перевод и оригинал.

Распознавание и перевод работают на телефоне, без интернета (словарь скачивается один раз, с VPN).

## Установить
Скачайте `.apk` из последнего релиза: **Releases → Latest → Perevodchik-ekrana.apk**.

## Обновить
В приложении кнопка «Проверить обновление» (с включённым VPN).
